# 自有渠道的余额与用量

- 自有渠道以渠道创建者与本次调用用户一致为判据，不按用户角色或渠道分组判断。
- 正式转发和管理端手动测试自己的渠道，均不扣 AiFerry 账户余额。自有渠道模型测试也不要求账户有余额。
- 自有渠道仍记录模型用量、估算成本，并跟踪渠道密钥的上游成本；这不代表 AiFerry 账户实际扣款。上游供应商仍可能扣除其账户额度。
- 测试其他用户创建的渠道，保持原有余额检查与扣费行为；系统巡检仍不扣账户余额。
- 新的模型测试日志保存计费明细，`charged` 仅在账户扣款成功后设为 `true`，避免将自有渠道的估算成本重建为实际扣款。
- 此修复不自动退款，不改历史日志。历史误扣必须逐笔核对调用用户、渠道归属及测试日志后，再单独授权处理。

本机验证：Go 全部单元测试、前端类型检查及前端测试。生产验收还需上线后核对真实自有渠道测试前后的账户余额和新日志的 `charged=false`；本机检查不代表生产已修复。
