# 渠道模型定时关闭

在渠道的「模型映射」弹窗里，除「选择模型」「配置映射」之外还有一个「关闭时间」页签，
用于按 **渠道 × 模型** 配置定时关闭时段：命中时段内该模型不再通过这个渠道提供，
时段过去自动恢复，不需要任何定时任务。

## 使用方式

1. 渠道列表 → 「发现与映射模型」打开弹窗；
2. 「选择模型」页签勾选要启用的上游模型（关闭时间只对这里已勾选的模型生效）；
3. 「关闭时间」页签点「添加关闭时段」手动加一行，在下拉里选目标模型，按需设置时区、星期与时段；
4. 「保存模型配置」。

「关闭时间」与「配置映射」同构：默认空列表，只显示手动添加过的模型，
不会把全部模型铺出来；同一模型只能占一行，删除即清除该模型的关闭配置。

典型用途：某个模型在上游按峰谷价计费，就在高峰时段把它从该渠道关掉，空闲时段自动恢复。

## 时段语法

```json
{ "tz": "Asia/Shanghai", "weekdays": [1, 2, 3, 4, 5], "ranges": [["09:00", "12:00"], ["14:00", "18:00"]] }
```

- `tz`：IANA 时区名，留空按 `Asia/Shanghai` 判定（容器本地时区是 UTC，不写时区会整体偏 8 小时）；
- `weekdays`：ISO 编号，1=周一 … 7=周日，留空表示每天；
- `ranges`：一天内的时段，可写多段；`start == end` 表示全天，`start > end` 表示跨零点（如 `22:00`–`06:00`）。

界面上的「工作日 / 周末 / 每天」按钮只是快捷填充星期，最终仍然落到这套结构。

## 判定与生效范围

- 判定发生在**网关路由阶段**（`internal/logic/relay/closed_window.go`）：命中的候选被摘掉，
  其余候选照常参与优先级、加权与故障转移。
- 关闭时段随时间变化，而路由候选会被缓存到 Redis，因此缓存里保存的是**未过滤**的静态候选，
  每次请求再按当前时间过滤一遍；关闭时段结束后候选自动回来，无需失效缓存。
- **只影响本渠道**：同一个公开模型如果还有其他渠道在服务，请求会照常路由过去。
  要让模型整体不可用，需要把所有提供该模型的渠道都加上关闭时段。
- 全部候选都被关掉时，沿用既有语义返回 `no available channel for model ...`
  （HTTP 404 `model not supported`），**不做隐式降级**；`/v1/models` 也只列出当前可路由的模型。
- 管理端的「模型测试 / 巡检」**不受**关闭时段影响，用于关闭期间仍可探活。

## 存储与接口

- 存储在 `channel_models.closed_windows_json`（迁移 `00040_channel_model_closed_windows.sql`），空值表示不关闭。
- `PUT /api/channels/{id}/models/selection` 的每条映射可带 `closedWindow` 字段：

  | 提交内容 | 语义 |
  | --- | --- |
  | 字段缺省 | 保持库里原值，用于「没配置过 / 未修改」 |
  | `{tz, weekdays, ranges}` | 覆盖为该时段 |
  | `{}` 或没有时段的空对象 | 清除已配置的时段 |

  写入前会校验：`tz` 必须是合法 IANA 时区，`weekdays` 必须是 1–7 的整数，
  `ranges` 必须是 `["HH:MM","HH:MM"]` 二元组；校验失败直接返回错误，不会落库。
- `GET /api/channels/{id}/models` 的每条模型带 `closedWindow`，未配置时为 `null`。

## 已知限制

- **不支持法定节假日与调休**：只有星期维度，无法表达「节假日全天关闭」；
  节假日需要当天手工关闭，或后续补 `dates` 日期列表。
- 时段按**请求进入网关的时刻**判定，跨时段的长请求不会中途切换。
- 未提供按模型统一关闭的入口：关闭是「渠道 × 模型」维度的，多渠道路由的模型要逐个渠道配置。

## 实现位置

- `internal/logic/timewindow`：时间窗解析、校验与命中判定（内嵌 `time/tzdata`）。
- `internal/logic/relay/closed_window.go`：路由阶段的候选过滤。
- `internal/logic/channel/models.go`：模型选择的读写与时段校验。
- `frontend/src/components/ChannelModelWindowPanel.vue`、`TimeWindowEditor.vue`：配置界面。
